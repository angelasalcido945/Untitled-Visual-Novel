# Untitled Visual Novel 

This visual novel is an in-progress interactive game being developed using Ren'Py and Python. 

## About the Project 

This is a personal project focused on building an interactive story through illustrated scenes, dialogue, character interactions, and branching narrative elements. 

The project is currently in development with portions of the main route already written and implemented in Ren'Py. 

## Technologies

- Ren'Py
- Python
- Git
- GitHub

## Current Features / Progress

- Scripted dialogue
- Prototype character and scene implementation in Ren'Py
- Ongoing development of the main story route
- Version control using Git and GitHub
- Project planning and milestone tracking

## Current Status

The main route is still being written and implemented. Additional illustrated scenes, story content, interactions, and features are planned as development continues.
